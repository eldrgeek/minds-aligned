Glocal memory is Goertzel's design principle that an artificial brain or mind should store knowledge in a dual, tightly linked way: *locally* as concrete instances, episodes, or localized structures, and *globally* as distributed patterns, maps, or abstractions that capture regularities across those instances. "Glocal" names this joint local-plus-global organization, in which neither sparse exemplar storage nor purely global distributed encoding is treated as sufficient for flexible general intelligence.

<strong>Ben Goertzel's lens:</strong> For Goertzel, glocality is not a casual blend of "local and global features" but a *critical* architectural requirement for artificial brains and minds—how concepts, sentences, and skills must be representable both as particular tokens and as reusable patterns. It rules out pure exemplar stores that never abstract and pure global embeddings that erase instance structure, and it departs from standard localist-versus-distributed debates by insisting the system maintain *both* layers in ongoing correspondence. In the broader patternist frame, glocal memory is how pattern recognition and instance-level control stay coupled so that learning, language, and reasoning can move fluidly between the particular and the general.
