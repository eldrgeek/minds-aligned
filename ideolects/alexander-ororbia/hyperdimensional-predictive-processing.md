Hyperdimensional predictive processing is a hybrid cognitive-architecture style that couples predictive-processing generative circuits—typically neural generative coding—with hyperdimensional or vector-symbolic memory models. High-dimensional distributed vectors support compositional storage and retrieval of roles, bindings, and episodes, while predictive-coding dynamics handle continuous inference, sensory prediction, and local learning as the agent navigates tasks such as maze learning, planning, and memory-dependent control.

<strong>Alexander Ororbia's lens:</strong> With Kelly, Ororbia uses this fusion as the kernel of CogNGen: a middle path between ACT-R-style symbolic cognition and Spaun/Nengo-style neural detail. Predictive processing alone is not enough for large-scale human-like memory operations; hyperdimensional codes alone lack the iterative mismatch-driven plasticity of neuro-mimetic deep models. The term rules out treating either tradition as sufficient by itself—under Ororbia it names the joint design that lets agents learn continually across diverse tasks while modeling performance at scales where pure neural or pure symbolic stacks struggle.
