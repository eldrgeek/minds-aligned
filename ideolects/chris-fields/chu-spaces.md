A Chu space is a category-theoretic structure pairing a set of objects (or tokens) with a set of attributes (or types) via a satisfaction relation—formally a bipartite incidence structure that generalizes matrices, topological spaces, and many forms of classification. In Fields and Glazebrook's program, Chu spaces (together with Barwise–Seligman Channel Theory) supply the formal language for semantically structured information flow: how observations classify situations, how contexts refine classifications, and how distributed systems share types without sharing a single global state description.

<strong>Chris Fields's lens:</strong> Chu spaces are not ornamental math; they are the working tools with which Fields models visual object files, categorisation, individual re-identification, mereological complexity, and context-dependent hierarchical Bayesian inference. Spatial coarse-graining, local logics, and channels between Chu spaces become the machinery of how finite observers build and maintain object identity over time. This rules out treating “context” as a vague pragmatic residual outside formal theory, and it departs from purely probabilistic or purely Hilbert-space formalisms that lack an explicit classification interface. For Fields, the Chu–channel mosaic is how cognitive science, logic, and quantum-information-style contextuality can speak one categorical dialect.
