The frame problem is the problem of determining, after an action, which features of an open environment remain unchanged and need not be updated. In Fields's usage it is not a narrow AI bookkeeping annoyance but a deep constraint on any finite observer: standard formulations smuggle in the assumption that objects can already be re-identified across pre- and post-action contexts, which is exactly what human cognition spends resources doing.

<strong>Chris Fields's lens:</strong> Fields argues that for humans the frame problem *is* the object re-identification problem—phenomenology and neurocognitive implementation both deploy the architecturally available information for tracking individuals, not for a separate “what stayed the same” module. Later work with Glazebrook embeds the same difficulty in quantum terms as a quantum frame problem tied to separability and contextuality; open-domain versions are linked to undecidability (including equivalence to the halting problem). This rules out classical frame axioms that assume a fixed inventory of named fluents, and it departs from standard AI readings that treat re-identification as trivial. The frame problem becomes a bridge between cognitive science and quantum information: whenever system boundaries and object tokens are approximate, “what did not change” cannot be settled by pure deduction.
