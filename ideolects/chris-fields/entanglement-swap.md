An entanglement swap is an operation in which entanglement between one pair of systems is transferred so that previously unentangled partners become entangled (classically, via a joint measurement and classical communication). In Fields's reconstruction of decoherence, the classical information that specifies the system–environment boundary is represented as a finite set of reference eigenvalues that any observer or apparatus must encode to distinguish system from environment; once that identification structure is explicit, decoherence itself can be described as a sequence of entanglement swaps between reference and pointer components of the system and their respective environments.

<strong>Chris Fields's lens:</strong> Semi-classical decoherence models typically assume ontic system–environment boundaries and then derive apparent classicality from entanglement with E. Fields inverts the accounting: the boundary information is classical and finite, and decoherence is the progressive swapping of reference and pointer entanglement rather than a mysterious collapse onto a pre-given cut. This rules out a priori ontic boundaries as inputs to the decoherence story, and it departs from textbook open-systems treatments that treat the S|E split as given before any dynamics. For Fields, entanglement swaps make system identification and decoherence one thermodynamic narrative.
