An inner screen is an internal classical information channel—structurally a Markov blanket—between components of a multi-component system, only some of which interact directly with the external environment. On this internal boundary, one subsystem can present finite-resolution classical records to another, so that attentional control, episodic memory, planning, and other imaginative experiences can be generated inside the system while still using the same spatio-temporal and object-recognition reference frames as ordinary perception.

<strong>Chris Fields's lens:</strong> Fields and coauthors apply the free-energy principle directly to conscious experience by treating imagination as inference over states on internal blankets rather than as a non-physical theater of qualia. Inner screens must allow internally generated content to remain surprising (prediction error is not zeroed by fiat) while remaining classically readable across the internal cut. This rules out models in which all Markov blankets sit only at the organism–world boundary, and it departs from dual-display metaphors that treat an inner screen as a passive movie for a homunculus. For Fields the inner screen is a thermodynamic and informational structure required by multi-component active inference, with large state and trait variability in humans as an empirical signature rather than a philosophical embarrassment.
