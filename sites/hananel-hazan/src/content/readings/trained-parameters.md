Across fifteen years and four substrates, one claim recurs in this record: the part of a system you train is not the part doing the work. It is stated as a rejection each time. "Memory via Temporal Delays in weightless Spiking Neural Network" (2022, Hazan first author, with Michael Levin) opens by naming the orthodoxy — "a common view in the neuroscience community is that memory is encoded in the connection strength between neurons" — and then builds a weightless network storing memory in timing instead. "A Little Rank Goes a Long Way" (2026, Hazan first author, with Levin) asks outright, "How many of a neural network's parameters actually encode task-specific information?", freezes every backbone weight at random, trains only low-rank adapters, and recovers 96–100% of full performance. "Training Ecosystems" (2026, with Levin) locates learning above the organism, with "memory implemented purely by dynamical interactions without explicit memory media." This is the archive's synthesis, not a claim Hazan has made in these words.
